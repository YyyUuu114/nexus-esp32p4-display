NEXUS Display v2.1.1 开发版
===========================

使用方法
--------
1. 完整解压整个文件夹，不要直接在压缩包内运行。
2. 双击“01-启动程序.cmd”或“Nexus Display.exe”。程序会先安装到受保护的 Program Files 目录，再驻留系统托盘。
3. 如需开机自启，双击“02-启用开机自启.cmd”；任务只指向受保护的已安装程序。
4. 如需取消开机自启，双击“03-取消开机自启.cmd”。安装本身不会启用开机启动。

运行要求
--------
- 支持 Windows 10/11 x64；发布包已包含 .NET 运行时。
- 读取部分硬件传感器与写入 Program Files 需要管理员权限，出现 Windows UAC 提示属于预期行为。
- ESP32-P4 原生 USB Serial/JTAG 不需要 CH340 驱动，也不依赖固定 COM 号。
- 程序通过协议 2.0 随机 nonce 双向握手确认设备，不会仅因某个串口可打开就视为开发板。
- 本版必须与 ESP32-P4 固件 v2.1.1 同步使用；v1.x 与 v2.x 混用会被拒绝。

数据与待机
----------
- 应用每秒发送日期、时间、CPU、GPU、内存、网络、风扇、温度、功耗和本次进程累计能耗。
- ENERGY 由有效 CPU 功耗与所有 GPU 功耗样本积分估算；开发板断开不会清零，应用重启时重新累计。
- 开发板连续 15 秒无活动时会停止背光、触摸、LVGL 与 MIPI-DSI；应用重新握手后自动恢复。

日志与更新
----------
- 日志位于“%LOCALAPPDATA%\NexusDisplay”。单文件上限 256 KiB，仅保留两份历史文件，并清理 7 天前的日志。
- 在线更新仅接受内置 ECDSA 公钥验证通过的官方清单和 SHA-256 匹配的 ZIP。
- 更新先写入受保护的 incoming 目录，再原子交换 current/rollback；新版启动失败时自动恢复上一版。
