NEXUS Display v1.2.1 开发版
===========================

使用方法
--------
1. 完整解压整个文件夹，不要直接在压缩包内运行。
2. 双击“01-启动程序.cmd”或“Nexus Display.exe”启动。
3. 程序常驻系统托盘，并自动识别 ESP32-P4 USB Serial/JTAG 端口。
4. 双击“02-启用开机自启.cmd”可启用登录自动运行。
5. 双击“03-取消开机自启.cmd”可取消登录自动运行。

运行要求
--------
- 支持 Windows 10/11 x64；发布包已包含 .NET 运行时。
- 读取部分主板传感器需要管理员权限，出现 Windows UAC 提示属于预期行为。
- ESP32-P4 原生 USB Serial/JTAG 不需要 CH340 驱动；程序不依赖固定 COM 号。
- 不要同时运行其他占用同一串口的采集程序。

数据与待机
----------
- 应用每秒发送日期、时间、CPU、GPU、内存、网络、风扇、温度和功耗。
- ENERGY 是本次应用进程运行期间 CPU 与 GPU 可用功耗的积分估算；开发板断开不会清零，应用重启时重新累计。
- 开发板连续 15 秒未收到合法数据时关闭背光；应用重新连接后自动恢复显示。

日志与更新
----------
- 日志位于“%LOCALAPPDATA%\NexusDisplay”。单文件上限 256 KiB，仅保留两份历史文件，并清理 14 天前的日志。
- 托盘菜单“检查更新”使用 HTTPS 清单和 SHA-256 校验安装包。
- v1.2.1 保持线协议 1.1，可与固件 v1.1.0 通信；开发版默认不配置在线更新源。
